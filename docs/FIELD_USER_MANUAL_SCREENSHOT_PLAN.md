# 현장 사용자 매뉴얼 화면 캡처 계획

이 문서는 `FIELD_USER_MANUAL_NOTEBOOKLM_SOURCE.md`에 실제 앱 화면을 붙일 때 사용하는 촬영 목록이다.

## 캡처 공통 규칙

- 실제 현장명, 사용자 이름, 비밀번호, 자격증명은 가린다.
- 날짜와 숫자는 교육용 시험 데이터로 촬영한다.
- 마우스 포인터를 눌러야 할 버튼 위에 놓는다.
- 원본 캡처와 빨간 화살표를 넣은 편집본을 모두 보관한다.
- 파일명은 아래의 캡처 번호로 시작한다.

## 필수 캡처

| 번호 | 화면 | 강조할 곳 | 그림 아래 설명 |
|---|---|---|---|
| U-01 | 상태표시줄 | 새 버전 확인 | 로그인 후 자동으로 확인하며, 필요하면 직접 누를 수 있습니다 |
| U-02 | 업데이트 발견창 | 버전과 진행률 | 창을 닫지 말고 기다리세요 |
| U-03 | Windows 설치창 | 설치 진행 막대 | 설치 중에는 PC를 끄지 마세요 |
| I-01 | 유량관리 그리드 | 선택 날짜 행, 통합입력 | 날짜를 먼저 선택한 뒤 통합입력을 누릅니다 |
| I-02 | 통합입력 전체 | 날짜, 네 개 탭 | 날짜와 작업할 탭을 확인합니다 |
| I-03 | 유량관리 탭 | 검침값, 자동계산 사용량 | 검침값을 넣으면 사용량이 계산됩니다 |
| I-04 | 수질 자동입력 | 서버에서 가져오기, 기간불러오기 | 하루 또는 기간 자료를 불러옵니다 |
| I-05 | 약품관리 탭 | 입고량, 사용량, 재고 | 세 값을 확인한 뒤 현재 탭을 저장합니다 |
| I-06 | 키트관리 탭 | 자동실험횟수 조회 | 조회 후 수량을 확인하고 저장합니다 |
| I-07 | 슬러지 입력 | 반출량, 반출사진, 청소필증 | 반출량을 입력해야 사진 버튼이 켜집니다 |
| L-01 | 일일업무일지 | 달력, HWP/PDF, 출력 | 날짜와 출력 형식을 선택합니다 |
| L-02 | 수질분석일지 | 데이터·사진 현황, 출력 | 누락 표시가 없는지 먼저 확인합니다 |
| L-03 | 약품입고일지 | 약품/키트 탭, 사진, 저장 | 사진 선택 후 반드시 저장합니다 |
| L-04 | 슬러지사진대지 | 날짜, 사진 두 종류, 출력 | 반출사진과 청소필증을 확인합니다 |
| C-01 | 성적서 미리보기 | 목록/미리보기, 체크박스 | 큰 그림을 보고 필요한 성적서를 체크합니다 |
| C-02 | 성적서 다중 선택 | 전체 선택, PDF 다운로드 개수 | 선택한 여러 장이 하나의 PDF가 됩니다 |

## 화살표 편집 순서

1. 첫 번째로 누를 곳: 빨간 원 `①`
2. 두 번째로 누를 곳: 주황 원 `②`
3. 마지막 저장 또는 출력: 파란 원 `③`
4. 기다려야 하는 영역: 시계 아이콘과 `잠시 기다리세요`
5. 누르면 안 되는 영역: 빨간 X

## 메뉴별 한 장짜리 간편 설명서 구성

```text
[큰 제목]

[전체 화면 캡처]
        ① 날짜 선택
              ↓
        ② 값 입력/사진 선택
              ↓
        ③ 저장 또는 출력

[초록 상자] 정상 완료 표시는 무엇인가
[주황 상자] 가장 자주 하는 실수
[하단] 문제가 생기면 현장명·날짜·화면 사진을 관리자에게 전달
```
