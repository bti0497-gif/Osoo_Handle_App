# 현장 환경 인벤토리

32 안정화 버전부터 수집하는 `electron / environment-baseline / observed` 진단 이벤트를 현장별로 정리하는 관리 문서다. 이 문서는 운영 코드의 설정값이 아니며, 진단로그를 분석한 뒤에만 갱신한다.

## 수집 원칙

- 패키지 앱이 서버 준비 상태에 도달한 뒤 앱 버전당 현장 PC별 1회만 기록한다.
- 기존 30분 진단 묶음 전송에 포함되며, 업무 화면·로그인·동기화 요청에는 개입하지 않는다.
- 비밀번호, 토큰, 인증서, API 키, 사용자 이름, 전체 파일 경로, 현장 DB 내용은 수집하지 않는다.
- 환경값이 없거나 읽기 실패해도 앱은 정상적으로 계속 실행한다.

## 진단 이벤트에서 확인할 항목

- 앱/런타임: 앱 버전, Electron·Chrome·Node 버전, 설치 범주
- 운영체제: Windows 버전·커널·아키텍처
- 자원: 시스템 메모리, AppData가 있는 디스크의 전체/여유 공간
- 로컬 실행 기반: SQLite 파일 존재, 서버 준비 상태
- 감시런처: 패키지 포함 여부, 최근 상태 파일의 버전·상태·확인 시각·유지보수 사유

## 판정 기준

- **준비됨**: 64비트 Windows, 여유 디스크·메모리 정상, 서버 준비 및 감시런처 상태 정상.
- **확인 필요**: 감시런처 상태 파일 부재, 디스크 여유 부족, 설치 범주가 예상과 다름.
- **선행 조치 필요**: 서버 준비 실패 반복, 감시런처 미포함/구버전, 운영체제 또는 아키텍처가 2.x 요구사항과 맞지 않음.

2.x 실제 요구사항과 임계값은 WinForms PoC와 배포 방식이 확정된 뒤 이 문서에 추가한다. 현재는 현장 환경의 기준선을 수집·비교하는 용도만 가진다.
