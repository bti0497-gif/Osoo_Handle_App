# 현장관리자 앱 팝업 공지 트레이 알림 보호 사양

- 현장 앱은 로그인된 일반 현장관리자 세션에서만 팝업 공지를 감시한다.
- 게시판의 기존 현장 가시성 판정 결과를 그대로 사용하며 별도의 전체 현장 우회 조회를 만들지 않는다.
- 활성 팝업 공지는 3분마다 조회하되 조회 실패가 로그인, 대시보드 진입 또는 다른 업무 기능을 막지 않는다.
- 최초 조회에서 이미 존재하는 공지는 기존 중앙 모달로 표시하고, 이후 새로 발견된 공지만 네이티브 알림 대상으로 삼는다.
- 앱 창이 숨겨졌거나 최소화되어 포커스를 잃은 경우에만 Windows 네이티브 알림을 표시한다.
- 알림 클릭 시 알림을 요청한 현장 창을 복원하고 최상단으로 포커스한 뒤 해당 공지 모달을 표시한다.
- 양방향 통합관리 창은 알림을 발생시킨 창의 현장 문맥을 유지하며 다른 현장 창을 대신 열지 않는다.
- `오늘 하루 보지 않기`는 사용자·현장·공지 ID별 만료 시각을 localStorage에 저장하여 24시간 재노출을 막는다.
- 24시간 이내 새 게시글이 있으면 소통게시판 메뉴에 `N` 배지를 표시하고, 사용자가 게시판을 열면 해당 배지를 즉시 해제한다.
- 공지 만료, 대상 현장, 권한 판정은 기존 게시판 서버 계약을 그대로 따른다.
- Electron IPC는 고정 채널과 길이가 제한된 공지 ID·제목·본문만 전달한다.
