# Osoo Handle App 1.1.53

이번 버전은 현장 사진 보존과 원격 로그인 진단을 보강합니다.

- 약품·키트 입고사진의 HEIC/HEIF를 JPEG로 변환해 저장합니다. 변환할 수 없는 파일은 원본을 로컬에 보존하고 Drive 전송 대기열에 넣으며, 미리보기가 불가능하다는 안내를 표시합니다. 허용 해상도를 넘는 사진은 원본 저장 우회 없이 거부합니다.
- 사진관리의 미리보기가 실패했을 때 저장 실패와 표시 실패를 구분해 안내합니다.
- 감시런처 1.0.11은 앱 창에서의 입력 신호를 내용 없이 집계합니다. 원격 세션 중 로그인 제출 시 세션·입력 요약을 진단용으로 기록하지만, 이번 버전에서는 원격 로그인이나 로그아웃을 차단하지 않습니다. 입력 경로는 아직 확정 판정하지 않습니다.
- 서버 복구 횟수 집계에서 상태 감시·요청·대기 이벤트를 실제 복구 실행으로 잘못 세지 않도록 정정했습니다.
- 릴리즈 회귀 러너는 변경 파일 유무와 무관하게 적용 대상 시나리오를 실행합니다.

참고: 안동 등 외부 네트워크/DNS 장애는 이번 변경만으로 원인 해결이 확인된 상태가 아닙니다. 해당 현장의 후속 진단로그를 계속 확인해야 합니다.
