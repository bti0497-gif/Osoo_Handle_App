## 미완료·별도 후속 항목

- 재고 위젯은 직전 구매량 분모와 비활성 품목 제외를 적용했으나 `inventoryLevelUtils.js`에는 응집제/PAC 등 활성 설정 이름을 묶는 추정 로직이 남았다. ROADMAP의 ‘정확한 품목명, 임의 통합 금지’ 후보가 전부 구현된 상태가 아니다. 현재 회귀 fixture는 응집제를 비활성으로 설정하여 두 이름 모두 활성인 조건을 검증하지 않는다.
- 날씨의 좌표별 조회·결측 0도 방지·캐시 갱신은 검토 문서만 작성했다. 하루 중 가장 심한 날씨를 사용한다는 정책은 사용자 확정이며 실제 공급자별 우선순위 검토가 남았다.
- 장비점검 저장/일지 두 페이지 연동은 스키마 사전 검토 단계다. 장비 UI Phase 1 개발은 별도 에이전트 담당.
- 구버전의 메모리 경고와 외부 로그인 이동 원인은 이 검토만으로 확정하지 않는다. 밤 서버 정지/아침 기동 정책도 구현 완료로 보고하지 않는다.
