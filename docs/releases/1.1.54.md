# Osoo Handle App 1.1.54 안정화 업데이트

- 월별 성적서는 로컬 자료를 먼저 표시한 뒤 Drive 목록과 대조하여 누락된 파일만 내려받습니다.
- QnTECH 수질분석 결과는 조회한 업무 날짜를 기준으로 저장하여 같은 날 분석한 결과의 날짜가 나뉘는 현상을 방지합니다. 기존 기록은 변경하지 않습니다.
- 장비이력카드 Excel 내보내기의 대표사진 및 연결된 작업 이력 바인딩을 보강했습니다. 대표사진은 화면에서도 잘리지 않게 표시합니다.
- 장비 공정에 부상조·제어반·기타를, 기기 종류에 막·제어반·기타를 추가했습니다. 기존 막분리조는 포기조와 같은 M-3 공정으로 유지합니다.
- 수리의뢰 금액은 기록에는 보존하되 유지비용 합계에서 제외하여 완료 작업과의 중복 집계를 방지합니다.
- 동기화 지연, 메모리 변화, 공사입력도우미 세션 복귀 및 원격 입력 관찰용 진단을 보강했습니다.

원격 입력 진단은 관찰용입니다. 이번 버전에서는 이 진단을 근거로 로그인이나 비밀번호 입력을 차단하지 않습니다. 비밀번호 및 실제 입력 내용은 진단에 기록하지 않습니다.

기존 현장 설정과 업무 데이터는 유지됩니다. Windows 7 호환판은 별도 배포 대상입니다.
