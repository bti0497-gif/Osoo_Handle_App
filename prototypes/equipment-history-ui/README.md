# 장비이력카드 UI 프로토타입

본앱의 라우트, API, DB와 분리된 UI/UX 확인용 폴더다.
개발 방식(사용자 확정): **이 폴더에서 UI를 먼저 다듬고 확정한 뒤 본앱에 이식한다.**
전체 계획은 루트 `docs/EQUIPMENT_CARD_DEVELOPMENT_PLAN.md`를 따른다.

## 실행

필드 앱 저장소 루트에서:

```powershell
npm run dev --prefix prototypes/equipment-history-ui
```

브라우저에서 `http://localhost:5180`을 연다.

## 공법과 기본 설비 목록

공법은 **기본설정에서 지정**되고(본앱 계약: `app_settings.method` = 'A2O' | 'MBR'),
장비이력카드는 그 값을 주입받아 **기본 설비 목록(시드)을 채운다**.
프로토타입에서는 사이드바 '설정'이 기본설정을 시뮬레이션한다.

- **A2O**: 침사조 - 유량조정조 - 포기조 - 침전조 - 응집침전조 - 방류조 (24종)
- **MBR**: 침전조·외부반송·응집침전 없음 + **막분리조**(막모듈·흡인펌프·막세척펌프·막분리유량계) (20종)
- 시드는 기본값일 뿐 — **장비 추가/수정/삭제로 현장 실정에 맞게 다듬는다.**
  "기본 2대 · 추가 시 C, D, E..." 같은 확장 관례는 비고 필드에 보관한다.
- 공법을 바꾸면 목록이 해당 공법 시드로 다시 채워진다(화면 편집 내용은 초기화, 확인 다이얼로그로 안내).

## 화면 범위

- 좌측 장비 목록 패널: 검색, **공정별/종류별 보기 토글**, 그룹 헤더, 대분류(기계/전기/계측기) 필터, 상태 배지, 공법 배지
- **장비 카탈로그 = 양방향 동기화**: 사용 중인 설비는 체크돼 있고, 체크/해제로 목록 등록·제거(제거 시 이력 정리 안내).
  개수형(펌프·교반기·브로아·막분리)의 `− n +` 스테퍼는 원하는 대수(늘리면 다음 호기 추가, 줄이면 높은 호기부터 제거).
  카탈로그에 없는 설비는 이름·공정·종류를 입력해 추가한 뒤 체크. 빈 양식 직접 입력은 '직접 입력으로 전환'으로 유지
- **관리번호 자동채번**(명명규칙 §3-6): 기계 `M-`, 유량계 `FLT-`, 수위계 `LIT-`, 계측기는 종류별 `DO-`/`PH-`/`MLSS-`.
  접두어별 독립 채번(최대값+1, 신규 접두어는 101 시작), 호기는 베이스 승계(M-103A/B → M-103C).
  직접 입력 양식은 이름에 맞춰 번호가 자동으로 따라가다가 수동 수정하면 그때부터 고정
- 우측 시설물 이력카드: 사양 그리드(비고 포함), 대표사진 영역, 요약 통계(누적 이력/비용/연간 비용/최근 이력)
- 탭 1 `장비 이력`: 점검·고장·수리 이력 테이블 + 행별 수정/삭제 + 이력 추가/수정 모달
- 탭 2 `연결된 업무·사진`: 업무사진관리에서 이 장비를 선택해 저장한 기록 목록(맞물림 미리보기)
- 장비 수정/삭제 모달(관리번호 중복 검사 포함), 확인/알림 다이얼로그
- 모든 변경은 메모리에서만 동작: 앱 세션 동안 유지, 새로고침 시 초기화

## 시뮬레이션 기록 (2026-09-06)

브라우저 자동화로 전 시나리오 통과:

- 1차(공법·CRUD): A2O 기본 로드 → MBR 전환(침전조·응집침전조 소멸, 막분리조 출현) →
  장비 추가/수정/삭제 → 이력 추가/삭제 → 새로고침 초기화
- 2차(카탈로그·호기): A2O 32대(호기 단위 카드) 로드 → 카탈로그 모달(등록됨 배지,
  '2대 등록 · 추가 시 C호기' 힌트 확인) → MLSS계 체크(LT-107 자동채번) →
  무산소조 교반기 2대(교반기 A/B 신규 그룹) → 유량조정조 교반기 +1(**M-103C** 이어증가) →
  저장(36대, 첫 생성 항목 자동 선택) → 새로고침 초기화(32대)

## 이력

- 초안: 공정별/종류별 그룹 테이블 스케치 (git 이력 참조)
- 1차: 마스터-디테일 이력카드 전체 UI (Phase 1)
- 2차: 공법별(A2O/MBR) 기본 설비 시드 + 공정별/종류별 그룹핑 + 기본설정 시뮬레이션
- 3차: 체크식 장비 추가 카탈로그 + 호기(A/B/C...) 단위 카드 모델 전환

UI 확정이 끝나면 본앱 `src/features/equipment/`에 접목하고 이 폴더 전체를 삭제한다.
